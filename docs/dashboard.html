Why closing one statement is so hard

Because "one statement" is a count of sentences, not a count of work. Here is the difference, without any notation.

A statement you can close by checking

"This particular object simplifies in four moves." That is a claim about one object. You run the moves, a checker confirms them, and it is closed. That is what the 154 successful cases are: 154 sentences, each closed by a verified sequence of moves.

A statement you cannot close by checking, however many times you check

"Every object of this kind simplifies." That is also one sentence. It is not one object, however. It stands for infinitely many, and no amount of testing closes it. Testing a thousand cases leaves the thousand-and-first open. The difference is the same as between "this number is odd" and "every even number above two is the sum of two primes." The second is one sentence. Nobody has closed it in 280 years, and it will not close by testing more numbers.

So the campaign is not sitting on a small leftover task. It is sitting on the kind of sentence that cannot be closed by working harder. It closes when a reason is found that covers every object at once — and the 154 successes are the evidence that such a reason exists, not the reason itself.

If it is so narrow, why is it not easy?

This is the fair challenge, and it deserves a real answer rather than the word "narrow". Narrow describes the sentence. It says nothing about the object the sentence is about. Seven reasons follow, in order of force.

One: the sentence is short and the set is infinite

The remaining claim takes one line to write. But it begins with "for every", and the set it ranges over is infinite in two directions at once: every length above twelve, and every arrangement of letters at each length. A short sentence about an infinite set is the normal shape of an unsolved problem, not evidence that the problem is nearly finished. Fermat's Last Theorem is one sentence. The Riemann hypothesis is one sentence.

Two: "every" is never discharged by examples

The campaign has now tested all 340 objects on the bottom layer. That is a complete measurement and it is worth having. It is also, as proof, worth exactly nothing on its own — because the claim is not about those 340. Testing is how you find out where the difficulty lives. It is not how you close a universal claim.

Three: the standard tool for this kind of claim is proved impossible here

When a mathematician has to prove "every path terminates", the standard tool is a quantity that falls at every step. It converts an infinite statement into one inequality. That tool cannot exist here, and this is not a matter of not having found the right quantity. Inverting a relator is a legal move in both directions, so between any two states joined by an inversion there is an arrow each way. A quantity that falls along every arrow would have to fall going out and fall again coming back. The impossibility uses no property of the quantity at all: length, defect, junction count, tail area — all excluded by the same two lines.

Four: the standard tool for the opposite answer is also shut

The other way to settle a universal claim is to refute it, by exhibiting one object that never simplifies — which requires an invariant that tells two presentations of the same group apart. Every group-theoretic invariant is blind here by construction: both sides present the same group, so the measurement returns the same value. The one published invariant that does separate such presentations requires a hypothesis the kernel proves our objects can never satisfy. So that tool is not merely missing; it is unreachable.

Five: both exits are shut by proof, and that is the whole difficulty

Normally a hard problem yields to one of the two: a termination measure, or a separating invariant. Both are individually ruled out by theorem — one by the symmetry of the move relation, the other by the structure of trivial-group presentations. What is left is not a harder version of either tool. It is a third kind of object: a construction performed separately on each state, with no global quantity behind it. That is why the problem is still open after sixty-one years. It is also why three working days moved it from an anonymous search space to one named statement with a measured wall around it.

Six: the only generic way to find a construction is search, and search is blocked by arithmetic

If you cannot compute a quantity and cannot compute an invariant, the remaining generic method is to look for the sequence of moves. That is a search. The measured barrier is at least thirty moves, and the branching factor is about eight, so the number of candidate sequences at that depth is roughly eight to the thirtieth — about ten to the twenty-seventh. A machine that examined a billion sequences a second would need longer than the age of the universe. Search is not slow here; it is arithmetically excluded at the depth that matters.

Seven: counting 340 does not license 340 separate arguments

There is a tempting misreading of the enumeration: 340 objects, so write 340 arguments. That fails twice. It fails practically, because each argument would need a sequence of thirty or more moves found and verified. And it fails logically, because the claim is uniform — a list of 340 cases says nothing about the layer above, and the layer above is infinite. A proof here has to be one uniform construction, not a table.

What the literature does give

The table above is a list of methods that cannot be applied. This is the opposite list, and it is the one that matters for the next cycle. Six published results bear directly on the open statement, and none of them is a general-purpose tool.

Bridson (2015). There exist trivialisable presentations whose shortest trivialisation exceeds any fixed tower of exponentials, with a small four-generator example above ten thousand digits of moves. This is a ceiling, not an obstacle: it says a path can exist and still be unreachable by enumeration, which is the argument for proving a descent rather than finding a path. It also tells you what a negative search result is worth, which is close to nothing.

Van Oostrom (1994), with Dershowitz and Manna (1979). Decreasing diagrams plus the multiset ordering give a well-founded order on paths when no well-founded order exists on states. That is exactly this campaign's situation: the impossibility theorem rules out every state measure, and the path measure is the substitute. It has been available since 1979 and the campaign's lane reached for it only in the last two days.

Lackenby (2026). Thickenable balanced presentations of the trivial group satisfy the unstable conjecture, with explicit bounds on stable moves. This is a live route that has not been tested, and the reason is mundane: the campaign's first attempt tested planarity of a four-vertex link, which is always true, so the search script returned "vacuous" rather than "no". The Neuwirth route — building the spine and checking manifoldness properly — has no implementation yet.

Carreras (2026). Our object is in this paper by name. P₆ is one of its two unresolved length-fourteen holdouts, and its Theorem 1 certifies the P₆-to-P₁ path in thirty-six packaged moves. That means the campaign's open case is a published benchmark rather than a private search target, and anything published about P₆ transfers here by citation.

Burns and Macedońska (1993). Balanced presentations of the trivial group, with the exponent-matrix machinery that makes the normal-form argument work. The matrix records how many times each letter appears in each equation. Being unimodular means its determinant is plus or minus one, so no equation in the list is redundant, and that is what every move-table determinant constraint in the corpus rests on.

Fagan (2024, 2026). The stable conjecture is equivalent to every contractible fake surface being three-deformable to a point, and the difficulty distribution across the problem is bimodal with a thin middle. The second is why added compute does not climb from the easy hump to the hard one, and it is measured by the organisers rather than asserted here.

The distinction worth carrying: no generic algorithm applies is a fact about the toolbox, and nothing in the literature helps is a different claim that happens to be false. Five of the six results above narrow the search rather than widen it, and two of them — the path measure and the thickenability route — are unbuilt.

What would count as a technique that works

A structural rewrite: one local transformation, stated once, that turns any interior state into a boundary state, with the proof that the boundary state descends. That would be uniform. It would cover every layer at once, and it would need no global measure. It is precisely what the campaign is looking for. The witnesses point at it: nine of the original eleven collapse one equation to a single letter and leave the other untouched, which is a local transformation rather than a global one. W39 has now supplied a computable test for when that transformation exists, which is the first step from a list of examples toward a stated rule.

The honest summary. Narrow means the campaign knows exactly which sentence to prove. It does not mean it knows how to prove it. The two standard ways to settle such a sentence are each ruled out by theorem. The generic fallback of search is excluded by arithmetic. What remains is one local construction, observed eleven times and not yet stated in general. That gap is the whole remaining difficulty, and no technique in the current toolbox closes it by being applied.

And the reason has not been found yet

What the last cycle established is that the obvious candidate reason — "simplify within four moves" — fails on 186 of the 340 objects, not the 329 the report said yesterday. That correction came from W39, and it is the reason this section now reads differently: the obvious reason works on 154 of them. So the remaining question is not "does a reason exist" but "what is the reason for the 186".

Why three to five hours is not enough, stated plainly

Three to five hours is enough to test a claim about one object, or to eliminate a route. It is not enough to close a claim about infinitely many objects, because that kind of claim needs an idea rather than effort. What the last five hours bought is real and it is different in kind: five routes closed by proof, the remaining layer counted exactly, the obvious candidate reason tested and found insufficient, and one stubborn case isolated. That is the diagnosis getting sharper. The cure is an idea, and ideas do not arrive on a cycle schedule.

Why these three people raised this problem

This is the question that turns a hard problem into an important one, and it has a specific answer: the organisers said why. Sergei Gukov, Terence Tao and Lucas Fagan announced the challenge on 11 September 2026, and their announcement gives three distinct reasons — a mathematical one, a structural one, and an admission.

The mathematical reason, in their words. The announcement opens by placing the problem, not by describing it:

"The Andrews–Curtis conjecture is one of the most prominent open problems in combinatorial group theory and also has deep connections to low-dimensional topology. Its potential counterexamples are relevant to the search for exotic smooth four-spheres and the smooth four-dimensional Poincaré conjecture, as well as the Generalized Property R conjecture about surgery on links." Fagan, Gukov and Tao, announcement of the challenge, 11 September 2026

Three named targets in two sentences: exotic smooth four-spheres, the smooth four-dimensional Poincaré conjecture, and Generalized Property R. That is why the problem is not a curiosity. A counterexample to Andrews–Curtis would not be a counterexample to a puzzle; it would be a construction feeding all three.

The structural reason: this problem is unusually well shaped for a competition. The organisers say it directly, and the reason matters more than it looks:

"Yet unlike many open problems at its level, Andrews–Curtis can be formulated as a combinatorial search problem with easily checkable solutions, making it ideal for a challenge of this form." Fagan, Gukov and Tao

That is a statement about the shape of the problem, not its difficulty. Most problems at this level cannot be handed to a crowd, because checking a submitted argument takes an expert days. Here a submission is a finite list of moves, and a program can replay it in milliseconds and answer yes or no. The organisers are saying: this is one of the few hard open problems at this level where a stranger's answer can be checked mechanically. The same property is what makes the campaign's Lean work possible — checkability, used differently.

The admission: their own programme is stuck. This is the part usually left out of competition announcements, and it is the most informative sentence in the post:

"At Caltech, we have been developing reinforcement learning and combinatorial search methods for this problem to resolve potential counterexamples… However, many important cases have resisted all our efforts. We hope that this challenge will lead to resolving these and more (or disproving the conjecture), especially given the recent progress in AI." Fagan, Gukov and Tao

So the team that built the state of the art on this problem — 753 presentations solved, two large public datasets released, several infinite families of potential counterexamples resolved — opened it to the public because their methods had stopped. That is what gives a proof or a disproof its weight here. For this group a disproof would resolve exactly the cases their agents cannot reach; a proof would mean those failures were a limit of search rather than a property of the mathematics.

Why search cannot settle it, in the organisers' own measurements

Their NeurIPS 2025 paper explains why the problem was chosen as an AI testbed in terms a non-specialist can follow. The action space is finite and small — a handful of legal moves at every step — while the state space is infinite. Instances come with a built-in notion of hardness, from trivially easy to cases that provably require superexponential effort. And the difficulty is distributed very unevenly across instances.

The follow-up paper names the consequence: the two-hump problem. Difficulty is bimodal. One large mass of presentations falls to greedy length reduction. A second large mass is effectively impossible for any current method. Between them sits a thin, sparsely populated valley of "hard but solvable" instances, and that valley is exactly where learning would have to happen. With almost no intermediate examples, an agent has nothing to train on.

That single structural fact is the strongest argument for why a proof matters more than more search. If the difficulty map has a gap in the middle, no amount of added compute climbs it. You do not get from the easy hump to the hard hump by trying harder; you get there by proving something about the structure of the space. The campaign's measure-based approach is a bet on exactly that — and the bet is not idiosyncratic, because it is the response the organisers' own data implies.

What the challenge actually asks

The conjecture is about lists of equations, and whether every list that cancels itself out can always be rewritten into the simplest possible shape using only three legal moves.

Take a list of equations written with letters. If the equations cancel each other out completely — if the structure they describe is what mathematicians call the trivial group — the conjecture says you can rewrite that list, step by step, until every equation is a single letter. There are exactly three permitted rewrites: you may invert an equation, multiply one equation by another, or conjugate an equation by a letter. Nothing else is allowed.

A worked example makes the shape concrete. The list ⟨x, y | xy, y⟩ cancels out, and it can be straightened in three moves:

start the presentation ⟨x,y | xy,y⟩
AC1 invert the second equation ⟨x,y | xy,y−1⟩
AC2 multiply the first by the second ⟨x,y | x,y−1⟩
AC1 invert the second again ⟨x,y | x,y⟩
Every equation is now a single letter. The conjecture asserts that this is always achievable, for every balanced presentation of the trivial group, at every size.

The problem has been open since Andrews and Curtis stated it in 1965. It matters well beyond its own field: a counterexample — a list that cancels out but cannot be straightened — would produce an exotic smooth four-dimensional sphere, which touches the smooth four-dimensional Poincaré conjecture and Zeeman's conjecture. That is why a question about rewriting rules sits at the frontier of topology rather than in a corner of algebra.

Stated formally, the theorem the competition asks for is this. Write n>0 for the rank, Relators(n) for the set of balanced relator lists on n generators, and standard(n) for the solved presentation ⟨x1,…,xn | x1,…,xn⟩.

AC  :  ∀n>0, ∀R∈Relators(n), PresentsTrivialGroup(R) ⇒ Reachable(R,standard(n))

Read plainly: for every size, every balanced list of equations that cancels out can reach the solved form. The stable version replaces Reachable with StableReachable, which permits adding and removing a do-nothing pair along the way.

Three ways to picture the problem

The conjecture is abstract, so mathematicians use three standard pictures to build intuition. Each one shows a different face of the same question, and each one makes a different part of this campaign visible. None of them is a metaphor invented here — they come from the topology literature and from the field's own teaching material.

Picture one · the rubber sheet

Loops of string, patches of rubber, and a peg

Draw one letter as a loop of string tied to a single central peg. Draw the second letter as a second loop on the same peg. Now take each equation in the list and turn it into a rubber patch: its edge is sewn onto the loops, following the exact path the equation spells out. Two letters, two equations, two patches — and if the equations cancel out, the whole object can in principle be shrunk down to the single peg with nothing attached.

The conjecture then asks a question that sounds like a party trick and is not. Can you always do the shrinking using only the moves available in three dimensions — sliding one patch across another, merging them, flipping them over? Or are some tangles so knotted that untangling them would require lifting the whole thing through a fourth dimension? A "yes" is the conjecture. A "no" would be a list of equations describing nothing, which nonetheless cannot be flattened in three dimensions.

Where this campaign stands in this picture. The reduction has already brought the object to the simplest form it can have while still being tangled: every patch is as small as it can be made, and nothing smaller is reachable. The open question is whether that final tangle can be slipped off the peg at all. In this picture the campaign has not been searching the space of all possible tangles — it has proved that every tangle reduces to one particular knot, and is now asking about that knot.

Picture two · the infinite maze

Every way of writing the equations is a room; every legal move is a corridor

Imagine every possible way of writing the list of equations as a room in a building. Two rooms are joined by a corridor exactly when one legal move takes you from one to the other. Somewhere in that building is a room called Home — the solved form, where every equation is a single letter. The conjecture says: from every room that cancels out, there is a corridor route to Home.

The cruelty of the maze is this. The route to Home often requires you to walk away from Home first — writing bigger, messier equations — before everything suddenly collapses and cancels. So a sensible strategy like "always take the step that makes the equations shorter" can get you stuck in a room with no way out. And by Bridson's result, some routes are longer than ten to the power ten thousand corridors, so you cannot find them by walking.

Where this campaign stands in this picture. The pivot — the one state at the frontier — is a room that has been checked to be a real one of the maze (it really does cancel out, proved twice by different methods). Its neighbourhood has been mapped: from that room, every corridor within thirty moves leads to a room that is no smaller. Over seventeen million rooms have been explored without finding a corridor to any known exit. If a route exists, it is long. If none exists, this room is an island — and an island is a counterexample to the conjecture.

Picture three · tunnels in clay

Drilling tunnels through a block, drawing curves on the surface

This is how Andrews and Curtis themselves framed it in 1965. Take a solid block of clay and drill a tunnel through it for each letter. Then draw curves on the clay's surface, one for each equation, following the path that equation spells out. An allowed move corresponds to handle sliding: physically dragging the mouth of one tunnel across the mouth of another, without tearing the clay.

The conjecture asks whether every completely tangled arrangement of surface curves can be unknotted purely by sliding tunnels around. The geometric content is immediate in a way the algebra is not: you can see that sliding can make a mess before it makes order, and you can see why a tangle might, in principle, be immovable without a tear.

Where this campaign stands in this picture. The endpoint of any successful route is a specific arrangement, and the campaign has now identified that arrangement by name in the published literature — P₁, the classical candidate studied by Johnson and by Burns–Macedońska. The pivot reaches it in forty-three slides, replayed and accepted by the archive's own verifier. So the question is no longer "does some arrangement work"; it is "can this particular tangle be slid into P₁, or is it stuck?"

The two things the competition asks you to prove

The Proof Track accepts a proof or a disproof of either of two conjectures. That gives four separate ways to win, and a submission only has to achieve one of them:

1

Prove the ordinary conjecture

Show that every list which cancels out can always be straightened. This is the 1965 statement.

2

Prove the stable conjecture

Show the same thing when a do-nothing pair of equations may be added and removed along the way. This is the easier of the two, and proving it alone is a complete win.

3

Disprove the ordinary conjecture

Exhibit one list which cancels out but cannot be straightened. The competition states that such a counterexample does not have to come from its own problem pool.

4

Disprove the stable conjecture

Exhibit one list which cannot be straightened even when the do-nothing pair is allowed.

The campaign is working both directions at once, and this is deliberate. The reduction chain, if it lands, produces a proof. The same pivot state, if it turns out to be stuck, produces a disproof. Those are not competing strategies; they are the two ends of the same object, and the campaign has spent the week measuring which end it is closer to.

It is strictly easier, and a proof of it alone is a full win on this track. Every statement needed is written and compiling; one proof remains.

Where the frontier is, and why it has not moved since 2003

"Frontier" here means something concrete and dated, not a mood. It is the smallest size at which the computers of the field stop being able to finish the job, and it has sat in the same place for twenty-three years.

By 2003 the two-generator case was closed completely up to twelve letters. Havas and Ramsay ran a breadth-first search in 2003, and Miasnikov and Myasnikov published the classification in 2001. Together they showed that every balanced two-generator presentation of the trivial group, with total relator length twelve or less, can be straightened. At thirteen letters the search stops finishing: the number of states grows faster than the machines do. The one candidate that sits exactly there — AK(3), total length thirteen — has resisted every attack since Andrews and Curtis wrote the problem down in 1965. So the frontier is not "a hard region". It is one specific shelf, fourteen letters and above, with the last confirmed foothold in 2003.

What this campaign did was move its own open question onto that shelf and give it a name. The state at the frontier is P₆, written in the July 2026 certificate archive as

P6 = MS(2, yx2y−1x−2 )

It is one of the two Miller–Schupp length-fourteen presentations that archive leaves unresolved. It is also the representative of the class the archive calls orphan idx1: 135,892 canonical states in which the archive finds no trivial presentation, no AK(3) through AK(7), and no idx0. The archive's own words at RESULTS.md:191 are that two of the three open length-fourteen candidates lie in that orbit. It reaches P₁, the classical candidate studied by Johnson and by Burns–Macedońska, in forty-three elementary moves; the archive's verifier replays the path and returns PASS. Our open case is therefore not one we invented. It is a named problem with a published address.

Why the Lean proof is the part that matters

A search result is a fact about the states a program happened to visit. A proof is a fact about every state at once. The campaign's central claim is of the second kind: that the whole sixty-one-year conjecture is exactly as hard as one named statement. That claim is only credible because every step of it is checked by the kernel. The comparison with the field's AI efforts is sharp for the same reason. The Caltech group solved 753 named instances and reported 0.0% success at turning any of them into machine-checked proofs, in their own table. Instances solved is a search result. A compiled chain is a proof. Only the second one can be submitted as a Proof Track result.

What the search results are for, then. They are not decoration and they are not a substitute. They tell the proof effort where to point. They established that the pivot really does present the trivial group, twice and by different methods. They established that its neighbourhood never dips below fourteen. And they established that the shortest known route to anything solvable is at least thirty moves. Without those measurements the one open statement would be unaddressed guesswork; with them it is a target with a map.

Why the frontier is hard, and why search cannot cross it

The objects at the frontier are the Akbulut–Kirby family, the shortest possible counterexample candidates. Every one of them presents the trivial group, and every one below n=3 is already known to be straightenable:

AK(n) = ⟨x,y |  xyx=yxy, xn=yn+1 ⟩

At n=3 the total relator length is thirteen — exactly one letter past everything the field has closed. That is the wall.

In 2015 Bridson proved that some lists which can be straightened nevertheless require more than ten to the power ten thousand moves. That number exceeds the number of atoms in the observable universe. The consequence is structural: no amount of computer search can cross the frontier by enumeration, because the path may exist and still be unreachable. Exhaustive enumeration dies at twelve letters; heuristic search dies against Bridson's bound.

The route this campaign took is neither of those. It builds a measure — a quantity that must strictly decrease at every legal move — so that a proof of descent replaces a search for a path. That is why the entire body of work below the frontier is a chain of theorems rather than a database of solved cases, and it is why the chain can be audited rather than trusted.

The risk that was raised — and how it closed

An earlier version of this page flagged a real defect risk: the statement the chain rests on asks for a smaller state inside the tidied family, and a general legal path is not obliged to stay there. Why this path is narrow, not merely further along

Every previous attack on this problem either enumerated a finite slice of presentations or solved named instances one at a time. This one compressed the statement itself, and that is a different kind of progress.

First: the scope of the question collapsed. The conjecture is a statement about every possible size of list and every possible list of equations at that size — two endless statements folded into one. Over four machine-checked steps, this campaign replaced that with a statement about one kind of object, and then with a statement about one object. The frontier is now a single presentation.

In ordinary language. Imagine a claim of the form "every human being who has ever lived, in every generation, will die." You cannot verify that by walking around. Now suppose you can prove, step by step, that this grand claim is exactly equivalent to one narrow claim: "the person standing in front of me will die." You have not solved the problem, but you have moved it somewhere you can put your hands on it. That is what happened here. An infinite statement was shown to be exactly as hard as one specific question about one specific object. Nothing was lost and nothing was assumed: every step of that translation is checked by a small computer program that refuses invalid reasoning, so the translation cannot be quietly wrong.

Second: the method changed from hunting a path to building a construction. Bridson proved in 2015 that some lists which can be straightened nevertheless need more than ten to the power ten thousand moves — a number larger than the atoms in the observable universe. So no computer search can ever settle this by exploring, because the path may exist and still be impossible to walk. The campaign's first response was to hunt for a quantity that must shrink at every legal move. W37 then proved that no such quantity can exist. The proof takes two lines against the move relation at AC.lean:36. Inverting a relator is a legal move in both directions, so a quantity falling along every arrow would have to fall going out and fall again coming back. What replaced the measure is a construction performed on each state: grow a relator along a cycle of conjugators, then collapse the growth with one multiplication. That device was read out of the 67-step kernel proof, where it appears as four verified motifs.

In ordinary language. You are lost in a mountain range at night and want the valley. Walking every corridor is hopeless — there are more than you could ever walk. You might hope to prove that every corridor slopes downhill, so the valley must lie at the bottom of the slope. That hope is closed here, and provably so: some moves can be undone exactly, and anything that slopes down away from a room must slope up coming back to it. What is left is more local and more laborious — for each room, exhibit a specific written-out route that reaches a room one floor down. The evidence that this can be done is the 229 verified routes the corrected enumeration has already produced, and if every room above the ground floor has one, the whole tower closes floor by floor, by induction. That is what the campaign is now trying to build: not one slope for the whole mountain, but one staircase per floor.

Third: the eliminations rule out whole families of strategy, not just individual attempts. Fifteen families of approach are now dead. The most recent closure is the strongest kind of argument available. Any two descriptions of the trivial group agree on every group-theoretic measurement, so no measurement of that kind can ever tell two of them apart. A separator, if one exists at all, must be something that is not a group measurement.

In ordinary language. A "group invariant" is anything you can compute from the equations that does not change when you legitimately rewrite them — the way a person's height does not change when they change clothes. If two presentations both describe the trivial group, then every such measurement returns the same answer for both, because they are the same group wearing different clothes. So no tool built from those measurements can separate them, however cleverly it is used. This is the difference between "we tried and it did not work" and "it cannot work, and here is the reason." The second permanently removes a whole family of future attempts, which is why a clean refutation is worth more to a campaign than another failed search.

Fourth: nothing below the frontier is a guess. Lengths one through four, the case where one equation is already trivial, the measure-ten layer, the measure-twelve layer — every one is closed either by a machine-checked proof or by a peer-reviewed paper. There is no case in the corpus described as "probably fine." Four of the five layers are compiled; the fifth is named.

In ordinary language. A machine-checked proof is not a proof that a person wrote carefully. It is a proof that a small program accepted — a program that knows only the rules of logic, cannot be persuaded, and rejects anything that does not follow. When this page says a case is closed, it means closed in the strongest sense mathematics currently offers: stronger than a referee reading it, because a referee can be tired and the program cannot. So what remains open is not a pile of unfinished work with uncertainty spread thinly across it. It is one named statement, and everything underneath it is settled.

Why mathematicians take this seriously — three fields, one problem

This is not a niche puzzle. It sits at a junction where three separate research communities each have a reason to care, and each reason is different. Understanding all three is what makes the campaign's position legible.

Topology: dimension four is the dimension where the machinery fails

In dimensions five and above, topologists have a complete toolkit. Surgery theory, the h-cobordism theorem and Whitehead's simple homotopy theory together answer the question "when are two complexes the same?" with an algebraic calculation. In dimension two the same question is answered by the classification of surfaces. Dimension four is the exception: the tools that work everywhere else break, and smooth four-manifolds behave differently from topological ones. That is not a gap in effort — it is a structural fact about the dimension.

The Andrews–Curtis conjecture is the combinatorial shadow of that failure. A presentation determines a two-dimensional complex, and the three legal moves are formal 3-deformations of that complex, in the sense made precise by Wright in 1973 and 1975. Stable equivalence corresponds to simple-homotopy equivalence, the relation Lustig developed in 1991 between Nielsen equivalence and simple-homotopy type. So a question about rewriting equations turns out to be a question about when a two-dimensional object can be collapsed — which is exactly the case the high-dimensional machinery cannot reach.

The dependency chain is recorded in the campaign's own deep research. Zeeman's 1963 result — that his collapsibility conjecture implies Andrews–Curtis — places the move set inside a chain of topological statements. The four-dimensional counterexample literature that made the problem famous is treated by Akbulut and Kirby (1985) and by Gompf and Stipsicz (1999). Two literature notes carry that chain with DOI-level references.

Combinatorial group theory: it is the field's standing open problem

Tao's description of the problem, quoted at the top of this report, is that it is "one of the most prominent open problems in combinatorial group theory". That is the field's own assessment, not the campaign's. Sixty-one years of work has produced a great deal of structure around it — normal forms, balanced presentation theory, the rank-two classification up to twelve letters — and no resolution. Every algorithmic technique the field owns has been pointed at it.

What the campaign added to that picture is a list of what does not work, proved rather than asserted. Fifteen families of approach are dead, and the most recent closure is structural: any two descriptions of the trivial group agree on every group-theoretic measurement, so a separator must be non-group-theoretic. For the field, that is a statement about the reach of its own standard toolkit — the invariants that resolve so much else cannot resolve this.

What this is worth outside mathematics

A conjecture about rewriting equations sounds like it belongs in a closed room. It does not. Four things downstream of it are concrete, and they are the reason the problem has survived sixty-one years of attack.

One: a counterexample would settle a question about the shape of four-dimensional space. In 1991 Gompf showed what a stuck presentation would produce: a fake four-dimensional sphere. Such an object cannot be told apart from the ordinary 4-sphere by any continuous deformation — that is what "homotopy equivalent" means. Yet it is a different smooth object, the way two maps of the same country can have different surfaces. That is the smooth four-dimensional Poincaré conjecture, one of the two great open problems of four-dimensional topology. The implication chain is written out in Riley's survey and in Kupers's notes: Andrews–Curtis sits beneath Zeeman's conjecture, and Zeeman implies the three-dimensional Poincaré conjecture where it applies. So this is not a technicality at the edge of a field. It is load-bearing for the geometry of dimension four.

Two: the stable version has its own geometric statement. Fagan's 2024 paper, written by one of the competition's own organisers, shows that the stable conjecture is equivalent to a statement about fake surfaces: every contractible fake surface must be 3-deformable to a point. He proves the case below complexity six. That equivalence matters for this report, because it turns the campaign's target into a statement about discrete geometric objects a computer can manipulate. That is why the problem is tractable by formal methods at all.

Three: it is a hard benchmark for machine reasoning, and the field is using it as one. The Caltech group trained reinforcement learning on 10,115 of these presentations and solved 753. The reason they chose the problem is that a single instance can require a very long sequence of moves with no useful intermediate signal: there is nothing to reward until the end. That is the shape of problem modern AI is worst at, which is why it is a useful test rather than a stunt.

Four: the machinery is the same machinery used elsewhere. Term rewriting, the algebra of handle slides, and the invariants built from balanced presentations all belong to the same toolbox as symbolic computation, computational group theory and the invariant constructions used in topological quantum field theory. The campaign does not claim a quantum-computing application here. It claims that the objects being manipulated are the standard objects of that toolbox, so progress on the structure of these presentations is progress on the toolbox itself.

Is this a toy? What actually transfers to applied work

The honest answer has two halves. The mathematics will not become a product. The search architecture might, because the same structural problem shows up in every sector where the rare event is the one that matters.

The structural problem is shared, not academic

Modern machine learning is built for the common case. It works because there are millions of examples of ordinary behaviour, and because the loss can be improved one small step at a time. Both assumptions fail in the places where the stakes are highest.

In finance the events that matter are tail events: a liquidity spiral, a correlated unwind, a funding run. There are very few of them, they do not repeat cleanly, and there is no useful signal until the position is already lost. In biotechnology they are rare adverse reactions and rare responders — a drug that helps one patient in two thousand, or harms one in twenty thousand. In cybersecurity they are intrusion paths nobody has walked before, where the attacker needs one route and the defender must find it first.

Each has the same three properties as the puzzle in this report. The reward arrives only at the end. The path is long and mostly wrong. And the interesting cases form a thin band between the overwhelmingly common and the effectively impossible — which is precisely what the organisers call the two-hump problem.

What the journalists actually reported

The Scientific American piece, published in August 2025, opens with a promise rather than a proof. It asks the reader to imagine knowing three things in advance: that the stock market will crash in three years, that extreme weather will destroy your home in eight, that you will develop a serious illness in fifteen. And it asks you to imagine acting now. It then says plainly that no current AI can do this, and that the Caltech work is a clue about how one might.

Gukov, the senior author, explains why they chose this particular problem:

"That was the reason we picked this problem, because it's a mathematical problem where, in order to make any progress, we basically are forced to develop new AI systems which can adapt to this level of complexity." Sergei Gukov, quoted in Scientific American, 11 August 2025

Ali Shehper, the first author, describes what the search feels like:

"Our program aims to find long sequences of steps that are rare and hard to find. It's like trying to find your way through a maze the size of Earth. These are very long paths that you have to test out, and there's only one path that works." Ali Shehper, quoted in the Caltech release, 13 February 2025

Why a crash forecast is the same shape of problem

Put the two side by side and the similarity is not a metaphor. To warn about a market crash you need to find a sequence of events that leads from ordinary conditions to a collapse. The sequence is long. Almost every step looks harmless. There is no signal along the way saying "you are getting warmer". And there is exactly one outcome you care about, at the far end.

That is the maze. It is also why ordinary machine learning does not help. A model trained on historical data learns what normal looks like, because normal is what fills the record. The rare event is, by definition, almost absent from that record — and you cannot make more of it. Nobody can run a thousand financial crises to generate training data, and nobody can ethically give a drug to twenty thousand people to see who reacts badly.

So the difficulty in both places is the same three things: a very long path, no feedback until the end, and almost no examples of the case that matters.

What the puzzle provides that a bank or a hospital cannot

In the maze you can manufacture the examples. You can generate as many puzzles as you like. You know in advance which have a solution, because you built them that way. And when a program proposes a route, you can check it by replaying the moves in milliseconds, with no argument.

That combination is what the real world never gives you. It is the entire point of using a mathematical puzzle: not that crashes and puzzles are alike in subject matter, but that the puzzle lets you practise the skill under conditions where you can tell whether you got it right.

What they built, in plain terms

Their system has two parts, and the second is the interesting one. One part plays: it tries moves, mostly fails, occasionally succeeds. The second part watches the first and looks for habits — stretches of moves that keep appearing in the solutions that work.

When it finds one, it writes it down as a single new move. The player can then take that whole stretch in one step instead of twelve. This is how a chess player learns an opening: not as twelve separate decisions each time, but as one remembered pattern with a name. The Caltech team call these learned shortcuts supermoves.

The consequence is that the search gets shorter without the player getting smarter. A route that needed a million steps can be walked in far fewer, because the repeated stretches have been compressed. That is how they closed problems that had stood for twenty-five and forty-four years.

Why that matters outside the maze

The same trick has an obvious analogue in risk work, and it is why journalists connected the two. A risk team does not want to be told "a crisis is coming" as one unexplained number. It wants to be told "this is a pattern we have seen before: funding gets short, then a large player is forced to sell, then the selling feeds itself". That sentence is a supermove. It is a recurring sequence, given a name, that can be watched for and acted on.

There is a second transfer the academic work does not emphasise, and regulated sectors care about it more than about any prediction. It concerns what can be shown after the fact.

In a regulated sector the equivalent artefact is the reason a supervisor accepts a model at all. Not "the model predicts a crash", but "here is the space of hypotheses we tested, here is what we killed, and here is the evidence that killed each one".

A prediction without a documented elimination record is an opinion. An elimination record is auditable — and in finance, biotechnology and cybersecurity, the audit is the product.

The honest limits

Three limits belong on the page rather than buried. First, what transfers is method, not result: this campaign's mathematics says nothing about markets or pathogens. Second, the puzzle's verifier is perfect while a regulated sector's is not, so methods that depend on instant checking degrade when the verifier is slow, partial or contested. Third, the middle of the difficulty curve is thin in reality too, so synthetic curricula must be built carefully — a crisis that cannot happen teaches the model the wrong lesson.

None of that makes the problem a toy. It makes it a wind tunnel: a place where the aerodynamics can be studied at full speed with the crashes contained.

Is this just Lean? An honest answer

This is the right question to ask, and it deserves a direct answer rather than a defensive one. Formalising mathematics is not the same as doing mathematics, and Terence Tao has been unusually clear about where the line falls.

Tao separates three things that a proof has to do. Generation is finding the argument. Verification is checking it is correct. Digestion is turning it into something a human expert can read, teach and connect to the literature. His June 2026 essay New mathematical workflows argues that AI has collapsed the first two and left the third untouched, producing what he calls proof indigestion: solutions that may be correct and are nevertheless not understood. He also draws a line between a "merely true" formalisation — code that compiles — and one that carries the implicit goals as well. Those implicit goals are readable structure, connection to the literature, and a community that can build on it.

Measured against that standard, here is where this campaign actually sits. Verification is done properly. 972 statements, three standard axioms, zero gaps, checked by a kernel rather than by a referee's patience. That is the part Tao says Lean does solve, and it is not a small thing: the reduction claims that an infinite statement is exactly equivalent to one named statement, and no human being could check that by eye. Digestion is what these two documents are for. The dashboard is the plain-English layer; the record is the layer with the file-and-line evidence, the literature support and the deep study index. A result that is compiled and inexplicable would fail Tao's third test, which is why the explainable report is not decoration bolted onto the maths — it is the part that makes the maths usable.

What the Lean work is not: a solution. It proves an equivalence, not the conjecture. The honest summary is that the campaign has built verification-grade infrastructure, located the whole difficulty in one named statement, and written the explanation — and that the remaining statement is still open, with the campaign's own estimate close to a coin flip. Anyone who reads "972 theorems" as "the problem is 78 per cent solved" is reading the wrong number, which is exactly why the paragraph under each bar on this page says what the percentage does and does not mean.

The short version

Lean here is doing the job Tao says it is good at — making a long chain of implications checkable by machine instead of trustworthy by reputation. It is not doing the job nobody has solved, which is finding the missing argument. The campaign's claim is therefore narrow and defensible: a verified reduction, a named open statement, a measured neighbourhood, and an explanation a non-specialist can follow. That is significant for the competition, because a Proof Track submission is judged on a proof or a disproof and this is neither yet. It is significant for the field either way, because the reduction is real and checkable whether or not the last statement falls.

Second, explaining a reduction is easier than explaining a discovery. A reduction has a natural narrative: link one implies link two, and here is why. Tao's own prescription is that formalisation plus better documentation relieves the indigestion. It is a worked example of his remedy, and the remedy works better than the diagnosis would suggest — because a record built during the work is easier to explain than a proof reconstructed after it.

The defensible claim, then, is narrow: a machine-assisted campaign can produce an explanation a non-specialist can follow, when the explanation is treated as a first-class output and paid for as the work proceeds. That is a weaker claim than "AI can explain itself" and a much stronger one than "AI produces black boxes."

What a world model is — and why this campaign is one

This has been described in the report as a verification effort. That was the wrong noun. What the campaign actually built is a world model of the problem, and the difference is the whole commercial argument.

The standard definition

The clearest short definition comes from the Stanford HAI issue brief on the world-model era:

"World models are AI systems that build a working representation of an environment to predict how it changes in response to action… A central goal of world models is counterfactual reasoning: predicting the consequences of an action, including actions the model was never explicitly trained on. This is a key distinction between a world model and a language model. A language model predicts what comes next in text; a world model predicts how an environment may change in response to an action." Stanford HAI, The World Model and Spatial Intelligence Era

The formal version, from the 2026 survey literature, gives the object a shape. An agent holds history h, takes action a, and the model predicts future states and task signals:

pθ ( zt+1:t+H , rt:t+H−1 ∣ ht , at:t+H−1 )

Ha and Schmidhuber's 2018 paper supplies the engineering intuition. A world model "can be trained quickly in an unsupervised manner to learn a compressed spatial and temporal representation of the environment." A policy can then "be trained inside the dream" the model generates, rather than in the environment itself.

What is unusual about this world model

In robotics the dynamics are unknown and the model approximates them. Here the transition rule is known exactly — three moves, written down in 1965 — and yet the space is unmanageable: a ball of radius twenty contains about 7.45 × 10¹⁷ states. So the model is not learning the physics. It is learning the geometry of reachability: which regions are dead, where the measure can descend, how far the nearest exit is, and which structure blocks progress.

That is why the elimination tree is not a report of failures. It is the model, drawn. Each closed branch is a region of the space that the model now knows is empty, and each closure carries the reason, which is what makes the knowledge transferable to the next problem.

Why "verification" was the wrong word

Verification is the reward channel, not the product. A kernel tells you that one trajectory is valid; a world model tells you which trajectories are worth trying before you spend anything checking them. The campaign built both, and for two weeks the report described only the cheaper one. The commercial asset is the model: it predicts what happens under searches that have never been run, which is exactly the counterfactual test the Stanford definition names.

The predicate, and the question it was answering

A descent search has to decide, for each state it reaches, whether that state is the thing the obligation asks for. The obligation asks for a state that is tidy and shorter than the start. The predicate in the search script asked for a state that is tidy and better than the best anything seen so far — a running minimum. Those are different questions, and they differ exactly when the first low state you meet is not tidy.

Walk the failure. The search starts at measure fourteen. It meets a neighbour at measure nine that is not tidy, so the running minimum becomes nine. Every tidy state at measure eight, ten, twelve or thirteen now fails the test "better than the running minimum" and is never checked for tidiness at all. The search continues, finds nothing, and reports that the shape has no exit. The witnesses were inside the ball the whole time.

Why the newer number is the trustworthy one

The independent recount used only moves that never raise the measure, which is a strict subset of the legal moves. A search restricted to a subset cannot find anything the full search missed — so if the subset finds twenty-nine in a shape where the full search found zero, the error is in the full search. That argument needs no code review and no trust: it is a containment.

What replaces the search

The same night produced the object that should have been used instead. Write the two relators of a state as words a and b. Let D of the pair be the smallest length you can get for the product a times a conjugate of b, minimised over every conjugating word. Then the state admits a two-move decrease exactly when D is smaller than the length of a.

The escapes land one layer down

The first two states that resisted five moves were run to depth six, and both descended. Neither landed on a solved form. Both landed at measure twelve.

That single observation changes what the remaining work is. The obligation does not demand that every state above the frontier reach a straightening in one series of moves. It demands a step down. And every state at measure twelve is already closed, by the published literature and by the proved low half of the chain. So if every state above twelve can be walked down one layer, the case above twelve follows from the case at twelve by induction on the measure — and the induction is a proof, where the search is not.

This is also why the impossibility theorem is not the obstacle it reads as. That theorem rules out a quantity that falls at every step of every path. It says nothing against a statement that is local to a layer and quantified per state, which is what an induction on the measure is.

What the framework says, in one paragraph

Because every move has an inverse, the state space is an undirected graph and the question is whether every orbit reaches a target of lower value. No function on states can decrease along every edge — that is the campaign's own impossibility theorem, independently confirmed. The framework's answer is to move the measure from states to paths: label each edge by the larger of its endpoint values, take the finite multiset of labels along a path, and order multisets by the Dershowitz–Manna multiset extension. That order is well-founded because the underlying order on numbers is, and it survives the two-cycles that killed every state measure. A path is reduced by replacing peaks with valleys, and each replacement strictly decreases the multiset.

state measure: m : X → ℕ impossible — inversion forbids it path measure: M(γ) = {{ max(m(a),m(b)) : edge a→b in γ }} well-founded reduction step: replace a peak u ← v → w by a valley below m(v) Dershowitz–Manna 1979, verified DOI 10.1145/359138.359142. The measure lives on derivations, not on states — which is why it does not contradict the impossibility theorem.

What this changes, and what it does not

It changes the obligation. Instead of "find a global measure" — proved impossible — the obligation becomes "close every local peak below its own height". That is local, finite per pair of moves, and it is the same object the campaign already half-constructed by reading its own proof.

It does not prove anything. The framework states its own failure mode plainly. A state can be a genuine local minimum from which every route out must climb far above it. When that happens, no amount of peak closing helps, and the height function is simply the wrong one. That configuration is testable rather than mysterious.

Why this is so hard

Five independent reasons, each of which would be enough on its own. Understanding them is what makes a two-hour cycle legible: the campaign is not slowly approaching an answer, it is systematically removing the ways an answer could be wrong.

Reason one: the space is enormous and the target is a single point

The branching factor is about 7.7, so a ball of radius twenty contains roughly 7.45 × 10¹⁷ states. At a million expansions per second that is 23,600 years of enumeration. And the goal is not "a better state" — it is one exact presentation, the standard pair. This is a needle, not a haystack gradient.

Reason two: the moves lengthen before they shorten

Three legal moves: invert, multiply, conjugate. None of them is required to make the presentation smaller. A route to the solved form almost always passes through states that are longer and messier than the start. So the obvious strategy — always take the step that shortens the words — gets stuck, and it gets stuck precisely on the hard cases. This is why the campaign had to prove a descent rather than search for one.

Reason three: no invariant can see the difference

This is the structural reason, and it is the one that kills most approaches before they start. Two presentations of the trivial group are the same group, so every group-theoretic measurement returns the same value for both. There is no fingerprint to compute. A separator, if one exists, has to be something that is not a function of the group — and nobody has found one in sixty-one years.

Reason four: a short path may simply not exist, and absence proves nothing

Bridson proved that some presentations which can be straightened require more than ten to the power ten thousand moves. So failing to find a short path is not evidence that no path exists. This is the cruellest feature of the problem: every negative search result is compatible with both answers, which is why the campaign had to stop searching and start proving.

Reason five: the frontier has been open, in this exact form, since 2003

Every two-generator case up to twelve letters is closed. At thirteen the field stopped, and the state the campaign is working on sits in a class of 135,892 canonical states that the July 2026 archive records as having no trivialisation and no obstruction. It is not that nobody looked. It is that the two obvious exits — find a path, find an invariant — both close.

And the reason progress feels invisible

Because this work pays out at the end or not at all. A cycle that closes a family produces no new theorem and no shorter path; it produces the knowledge that a region is empty. That is real, it is recorded, and it is what makes the surviving branch narrow — but it does not move the number that says whether the conjecture is true.

So two honest sentences sit side by side after every cycle. We know more about the space than we did this morning. We are no closer to knowing the answer. Both are true, and anyone reporting only the second is describing a wasted day that did not happen.
