# Security policy

## Supported versions

The current minor release receives fixes. Earlier minor releases do not.

## Reporting

Report a vulnerability through the organisation's internal support channel. Do
not open a public issue. Include the affected file, a minimal reproduction, and
the commit hash. A first response follows within five working days.

## What this repository does not contain

No credentials, no customer data, no network services. The corpus is a Lean
development plus documentation. The build runs offline against a pinned
toolchain.
